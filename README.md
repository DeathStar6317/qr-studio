# QR Studio

A modern, customizable QR code generator and designer built with **React, TypeScript, and Vite**.

🔗 **[Try QR Studio Live](https://qr-studio-rho-seven.vercel.app/)**

Create, customize, preview, and download QR codes through an interactive, responsive interface.

## ✨ Features

### QR Code Generation
- Generate QR codes for URLs and website links
- Create QR codes for plain text
- Generate email and phone QR codes
- Create Wi-Fi QR codes for network sharing

### Customization
- Choose from 12 built-in QR themes
- Customize foreground and background colors
- Apply gradient styling
- Adjust QR code size and margins
- Configure error correction levels: L, M, Q, and H
- Switch between light and dark modes

### User Experience
- Real-time QR code preview
- Download QR codes in PNG or SVG format
- Copy generated content
- Access recently generated QR codes
- Save recent data locally in the browser
- Responsive interface for desktop and mobile
- Input validation and QR readability checks

## 🛠️ Tech Stack

## 🚀 Getting Started

Follow these steps to run QR Studio locally.

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- npm (included with Node.js)
- Git installed

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/DeathStar6317/qr-studio.git
```

**2. Navigate to the project directory**

```bash
cd qr-studio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.

### Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
